# Sensor Data Visualisation Code

Codebase for processing multi-sensor time-series data and generating visualisations and summary tables.

## Repository Structure

- `config.py` : Configuration settings and variable definitions.
- `utils.py` : File detection, data loading, preprocessing, and plotting helper functions.
- `stations.ipynb` : Notebook workflow for station-level processing, visualisations, and summary exports.
- `stations_cumulative.ipynb` : Notebook workflow for generating cumulative visualisations across multiple participants.

## Notice

This code was developed as part of an ongoing research study that has not yet been published. Therefore, no original study data or actual visualisation examples are included in this repository.

Certain values, including example dates, timings, file paths, and preprocessing parameters, have been replaced with placeholders.

No participant data or other confidential study materials are shared in this repository.
